# Annotating Handbook 
- Action States
  - Idle is when the tool is not doing any actions
  - Some action also counts when the tool is not necessarily interacting but either will or is in the process
- Depth State
  - Will always be null unless one tool occludes the other
  - When one tool occludes the other tool, the tool closest to camera is 1 and the tool later than it is 2 or more
- The other attributes are self-explanitory
